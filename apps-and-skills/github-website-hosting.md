# 8️⃣ Github web page hosting

1. Create a new repository\
   for example: {repository-name}
2. In the Settings of {repository-name}, click Pages on the left menu
3. Select main and /(root) in Branch
4. ng build --base-href "https://\*\*\*\*\*\*.github.io/{repository-name}/"
5. Select code of the {repository-name}
6. Click Add file button to upload files
